Match rules

Matches are first to 5 points. As soon as either side reaches 5, the match ends and this browser releases control for another player.

Single-player lock

The browser holding the controller can play. Other visitors are spectator-only and cannot send paddle input or frames.

If the active browser closes or disconnects, its controller lock expires automatically after a few seconds.

Takeover rule

A/D: claims the top paddle and disables top AI.

←/→: claims the bottom paddle and disables bottom AI.

Scoring

A point is awarded only when the opponent misses. A paddle deflection never changes the score.
