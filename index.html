How people play

Same-device multiplayer: choose “2 players — same device.” One person controls the top paddle with A/D; the other uses the arrow keys.

Remote multiplayer: not yet. That requires a small realtime server to synchronize two browsers. The building API only receives display frames.

Building viewer

The browser game sends the same 17×9 RGB frame shown on the left to the Sundai simulator. A persistent AI Pong clip also runs whenever no live player is sending frames.
